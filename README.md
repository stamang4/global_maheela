# Global Maheela website prototype

Open `index.html` in a browser. The site is intentionally dependency-free.

## Gallery images
Replace any `.placeholder` figure in `index.html` with an `<img>` plus a useful `alt` description, or set a real image inside the figure. Keep meaningful images described; use empty alt text only for purely decorative images.

## Before launch
- Replace the sample contact email with the official address.
- Connect social, Bhirkuna, forms, events and resource links to their final destinations.
- Add the organization's real photographs to the gallery and story cards.
- Run keyboard, screen-reader, 200% zoom and automated accessibility checks after real content is inserted.

## Accessibility built into this prototype
Semantic headings/landmarks, skip link, keyboard focus treatment, large targets, strong text contrast, responsive layout, no information conveyed by color alone, and reduced-motion support.
